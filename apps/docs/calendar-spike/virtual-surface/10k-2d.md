> **Status:** Stub (Phase 0, Day 1) — implementation lands as Spike A progresses.

## Question

Validate `<VirtualizedSurface>` with `axis="both"`. Logical grid of 1.000 ×
1.000 = 1 M cells, only ~200 ever visible. Drag-scroll in both axes. The 2D
math is the foundation for the v2 timeline view; we ship it in v1 to avoid
refactor later (see design doc v0.2 §0.6).
