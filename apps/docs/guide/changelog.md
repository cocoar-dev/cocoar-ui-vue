# Changelog

**Release notes are the [GitHub releases](https://github.com/cocoar-dev/cocoar-ui-vue/releases)** — one per
version, `https://github.com/cocoar-dev/cocoar-ui-vue/releases/tag/vX.Y.Z`. Each lists the changes since the
previous version, grouped as breaking changes, features, fixes and documentation, and a feature release starts
with a short tour of what is new.

Upgrading across a major version: see [Migration](./migration).
